# 로그인용 이메일 주소 변경하기

## 이 글에서는

로그인 이메일 주소를 바꾸고 싶을 때, 새로운 이메일 주소로 같은 워크스페이스를 이어서 사용하는 방법을 안내합니다.

***

## 로그인 이메일 주소 변경 방법

스티비는 로그인 이메일 주소를 직접 변경하는 기능을 제공하지 않습니다. 대신 새로운 이메일 주소를 워크스페이스에 사용자로 초대하면, 새로운 계정으로 로그인해 같은 워크스페이스를 사용할 수 있습니다.&#x20;

목적에 따라 필요한 작업이 다릅니다.

* 새 이메일 주소로 로그인하고 싶다면: 새로운 이메일 주소를 '관리자'로 초대합니다.
* 기존 계정을 탈퇴하거나 더 이상 쓰지 않으려면: '관리자'로 초대한 뒤 워크스페이스 소유자를 새로운 이메일 주소로 변경합니다.



## 요금제별 로그인 이메일 주소 변경 방법

* 스타터 요금제: 사용자를 1명만 둘 수 있어 다른 이메일 주소를 초대할 수 없습니다.
  * 사용 기록이 없다면 [탈퇴](withdrawal.md)한 뒤 새로운 이메일 주소로 다시 가입합니다.
  * 사용 기록이 있다면 스탠다드 이상 요금제로 변경한 뒤 아래 방법을 따릅니다.
* 스탠다드, 프로, 엔터프라이즈 요금제: 아래 방법으로 새로운 이메일 주소를 초대합니다.

### 새 이메일 주소를 관리자로 초대하기

> 💬 이 내용은 **스탠다드, 프로, 엔터프라이즈 요금제**에 해당하는 도움말입니다.

1. 화면 오른쪽 위 \[워크스페이스 이름]을 클릭하고, \[워크스페이스 설정 → 사용자 관리]로 이동합니다.
2. \[초대하기]를 클릭하고 새로운 이메일 주소를 입력한 뒤, 권한을 '관리자'로 선택합니다.
   1. 프로, 엔터프라이즈 요금제에서는 [다양한 권한](../settings/user-permissions.md)을 설정할 수 있습니다.
3. 로그아웃한 뒤, 새로운 이메일 주소로 받은 초대 메일에서 \[워크스페이스 가입하기]를 클릭합니다.
4. 새로운 이메일 주소로 가입하거나 로그인합니다. 초대받은 이메일 주소가 아니면 초대를 수락할 수 없습니다.

{% hint style="info" %}
관리자는 워크스페이스 삭제와 소유자 변경을 제외한 모든 기능을 사용할 수 있습니다. 권한별 기능은 [사용자 권한 설정하기](../settings/user-permissions.md)에서 확인할 수 있습니다.
{% endhint %}



## 워크스페이스 소유자 변경하기

기존 계정을 탈퇴하거나 더 이상 쓰지 않는다면 소유자를 변경합니다.

1. 기존 소유자 이메일 주소로 로그인합니다.
2. \[워크스페이스 설정 → 사용자 관리]에서 새로운 이메일 주소 오른쪽의 \[더 보기(···) → 권한 변경하기]를 클릭합니다.
3. 권한을 '소유자'로 변경합니다.

**\*주의:** 소유자를 변경하기 전에 기존 계정을 탈퇴하면, 기존 계정이 소유한 모든 워크스페이스가 삭제되고 복구할 수 없습니다. 반드시 소유자를 먼저 변경해 주세요.

{% hint style="info" %}
워크스페이스가 여러 개라면 워크스페이스마다 같은 과정을 진행해야 합니다. 요금제는 워크스페이스 단위로 적용됩니다.
{% endhint %}
