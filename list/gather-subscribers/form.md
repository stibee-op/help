# 구독 받기

## 이 글에서는 <a href="#h_01hfna4p2h02gnxargrck6ft11" id="h_01hfna4p2h02gnxargrck6ft11"></a>

구독 폼으로 구독 신청을 받는 방법을 안내합니다. 구독 폼 설정과 수정, 구독 확인 이메일, 홈페이지에 구독 폼을 넣는 방법까지 순서대로 살펴봅니다.

***

## 구독 폼 이해하기 <a href="#h_01ggcbmn0c7yk62feh8bwj7xg6" id="h_01ggcbmn0c7yk62feh8bwj7xg6"></a>

구독 폼은 새로운 구독자에게 이메일 구독 신청을 받는 입력 폼입니다.

구독 폼은 주소록과 연결되어 있습니다. 주소록을 만들면 구독 폼도 자동으로 만들어집니다. 구독자가 구독 폼에 이메일 주소를 입력해 구독을 신청하면, 연결된 주소록에 자동으로 등록됩니다.

구독 폼 예시는 아래에서 확인할 수 있습니다.

* [<스티비 뉴스레터>](https://page.stibee.com/subscriptions/3)
* [<위클리D>](https://page.stibee.com/subscriptions/29178)
* [<커피팟>](https://page.stibee.com/subscriptions/52057)

![](<../../.gitbook/assets/1 (11).png>)



구독자는 구독 완료 화면에서 구독한 날짜와 시간을 직접 확인할 수 있습니다. 구독할 때 광고성 정보 수신에 동의했다면 동의했다는 문구가 함께 표시됩니다.

## 구독 폼 설정하기 <a href="#h_01ggcbmvd2pm93jfz25n2z1kc2" id="h_01ggcbmvd2pm93jfz25n2z1kc2"></a>

구독 폼은 \[주소록 → 구독 화면]에서 설정합니다.

1. \[주소록]을 클릭합니다.
2. 구독 신청을 받을 주소록을 선택합니다.
3. 주소록 메뉴에서 \[구독 화면]을 클릭합니다.
4. 화면 맨 위 \[구독 폼] 영역을 확인합니다.

\[구독 폼] 영역에서 언어, 활성화 여부, URL 등 기본 설정을 관리할 수 있습니다.

<figure><img src="../../.gitbook/assets/구독 폼 설정하기.png" alt=""><figcaption></figcaption></figure>



## 언어 선택하기

구독 폼, 구독 확인 이메일, 구독 정보 변경 화면에서 사용할 언어를 선택할 수 있습니다. 기본 언어는 한국어이며, 영어로 바꿀 수 있습니다.

{% hint style="info" %}
언어를 영어로 바꿔도 구독 폼의 제목, 버튼 이름, 입력 항목 이름은 자동으로 번역되지 않습니다. 예를 들어 '이메일 주소'가 'Email Address'로 바뀌지 않습니다. 필요한 항목은 \[구독 폼 → 수정하기]에서 직접 수정해 주세요.
{% endhint %}

<figure><img src="../../.gitbook/assets/구독 폼 언어 선택하기.png" alt=""><figcaption></figcaption></figure>



## 구독 폼 활성화 설정 <a href="#id-01hh1t1m2chswbxwsz6rvfh143" id="id-01hh1t1m2chswbxwsz6rvfh143"></a>

구독 폼을 사용할지 설정할 수 있습니다.

* 활성화: 구독 폼 URL로 구독 신청을 받을 수 있습니다.
* 비활성화: 구독 폼 URL로 접속해도 구독 폼이 표시되지 않습니다.

페이지와 연결한 주소록의 구독 폼을 비활성화하면 페이지의 \[구독하기] 버튼도 표시되지 않습니다.

![](<../../.gitbook/assets/3 (11).png>)



## 구독 폼 URL 확인하기 <a href="#h_01ggcbn8tqknhrf5wfxpwzn8gv" id="h_01ggcbn8tqknhrf5wfxpwzn8gv"></a>

\[주소록 → 구독 화면]의 \[구독 폼] 영역에서 구독 폼 URL을 확인할 수 있습니다. URL은 자동으로 만들어지며 수정할 수 없습니다. \[URL 복사하기]를 클릭하면 URL이 복사됩니다.

![](<../../.gitbook/assets/4 (10).png>)



## 구독 폼 정보 수정하기 <a href="#h_01ggcbne0xarz8tagb4jctaedf" id="h_01ggcbne0xarz8tagb4jctaedf"></a>

\[수정하기]를 클릭하면 구독 폼에 표시되는 정보를 수정할 수 있습니다. 수정할 수 있는 항목은 다음과 같습니다.

* 헤더 이미지
  * 구독 폼 맨 위에 표시되는 이미지입니다.
  * 가로 550px 이상을 권장합니다. 가로 550px보다 작으면 왼쪽으로 정렬됩니다.
* 제목
  * 구독 폼 맨 위에 표시되는 제목입니다.
  * 기본값은 '주소록 이름+구독하기'입니다.
* 내용
  * 제목 아래에 표시되는 상세 내용입니다.
* 구독자 입력 정보 설정
  * 구독 신청할 때 입력받을 정보를 설정합니다.
  * 이메일 주소는 필수이며 맨 위에 고정됩니다. 이름 등 나머지 항목은 선택이며 순서를 바꿀 수 있습니다.
  * 입력받을 정보를 추가하려면 사용자 정의 필드를 먼저 만들어야 합니다. 자세한 내용은 [사용자 정의 필드](../adding-managing-subscriber/understanding-subscriber-info.md#custom-fields-1) 도움말을 참고해 주세요.
* 개인정보 수집 및 이용 동의 표시
  * 체크박스 형태로 표시됩니다.
  * 표시되는 내용을 편집하고 텍스트 스타일을 설정할 수 있습니다. 내용을 입력하지 않으면 기본 문구가 표시됩니다.
* 광고성 정보 수신 동의 표시
  * 광고성 정보가 포함된 이메일을 보낼 때 필요한 동의 항목입니다.
  * 체크박스 형태로 표시되며, 필수 또는 선택 여부를 설정할 수 있습니다.
  * 구독 폼에는 '마케팅 목적의 개인정보 이용 및 광고성 정보 수신 동의'로 표시됩니다.
  * 표시되는 내용을 편집하고 텍스트 스타일을 설정할 수 있습니다. 내용을 입력하지 않으면 기본 문구가 표시됩니다. 작성 방법은 아래 '광고성 정보 수신 동의 내용 수정하기'를 참고해 주세요.
* 자동 입력 방지(reCAPTCHA) 표시
  * 스팸 봇의 비정상적인 구독 신청을 막습니다.
  * 코드로 설치한 구독 폼에는 표시되지 않습니다.
* 버튼
  * 입력한 정보를 제출하는 버튼입니다. 구독 폼에 항상 표시됩니다.
  * 버튼 이름, 배경 색상, 텍스트 색상을 바꿀 수 있습니다.

<figure><img src="../../.gitbook/assets/구독 폼 수정하기.png" alt=""><figcaption></figcaption></figure>



### 광고성 정보 수신 동의 내용 수정하기

광고성 정보 수신 동의 내용은 구독자가 동의 문구를 클릭하면 볼 수 있는 상세 설명입니다. 마케팅을 위해 어떤 개인정보를 어떻게 이용하는지 구독자에게 알리는 역할을 합니다.

내용을 입력하지 않으면 아래 기본 문구가 표시됩니다.

> 마케팅을 위한 개인정보를 수집하고 이용합니다. 수집된 정보는 마케팅 외 다른 목적으로 이용되지 않으며, 서비스가 종료되거나 동의를 철회하면 즉시 파기됩니다.

기본 문구에는 구체적인 항목과 목적이 담겨 있지 않습니다. 실제로 수집하는 개인정보 항목과 이용 목적에 맞게 내용을 수정해 주세요. 아래 내용을 포함하면 좋습니다.

* 이용 목적: 어떤 마케팅 정보를 보내는지 적습니다. (예: 신규 서비스 안내, 이벤트, 프로모션, 할인 혜택)
* 이용 항목: 마케팅에 이용하는 개인정보 항목을 적습니다. (예: 이메일 주소, 이름)
* 보유 기간: 개인정보를 언제까지 보관하는지 적습니다. (예: 동의를 철회할 때까지)
* 동의 철회 방법: 수신을 원하지 않을 때 철회하는 방법을 적습니다. (예: 이메일 하단의 수신거부 링크)

<figure><img src="../../.gitbook/assets/광고성 정보 수신 동의 수정 화면.png" alt=""><figcaption></figcaption></figure>



작성 예시는 다음과 같습니다.

{% hint style="info" %}
아래 예시는 참고용입니다. 필요한 내용은 수집하는 정보와 이용 목적에 따라 달라질 수 있으므로, 정확한 기준은 내부에서 확인해 주세요.
{% endhint %}

> 신규 서비스 안내, 이벤트, 프로모션, 할인 혜택 등 마케팅 정보를 이메일로 보내기 위해 개인정보를 이용합니다.
>
> * 이용 목적: 마케팅 정보 제공
> * 이용 항목: 이메일 주소, 이름
> * 보유 기간: 동의를 철회할 때까지
>
> 동의한 뒤에도 이메일 하단의 수신거부 링크를 클릭해 언제든지 동의를 철회할 수 있습니다.

**\*주의:** 코드로 설치한 구독 폼에는 변경된 문구가 자동으로 반영되지 않습니다. 코드를 다시 복사해 교체해 주세요.



## 구독 확인 이메일 <a href="#confirm_email" id="confirm_email"></a>

구독 확인 이메일은 구독 신청 직후 구독자에게 발송되는 이메일입니다. 구독자가 이메일의 구독 확인 링크를 클릭해야 주소록에 등록됩니다.

구독 확인 링크는 24시간 동안 유효합니다. 24시간이 지났다면 구독을 다시 신청해 새 링크를 받아야 합니다.

### 발송 여부 설정하기

\[구독 확인 이메일 발송하기]를 클릭하면 발송 여부가 바뀝니다.

* 활성화: 구독 확인 이메일이 발송됩니다. 확인 과정이 하나 늘지만, 잘못된 이메일 주소나 스팸 봇의 구독 신청을 막을 수 있습니다.
* 비활성화: 구독을 신청하면 바로 주소록에 등록됩니다. 구독 과정이 짧아지지만, 잘못 입력된 이메일 주소를 걸러내기 어렵습니다.

안정적인 발송을 위해 구독 확인 이메일을 사용하는 것을 권장합니다. 자세한 내용은 [뉴스레터에 구독 확인 이메일이 필요한 이유](https://blog.stibee.com/nyuseureteoe-gudog-hwagin-imeili-pilyohan-iyu/)를 참고해 주세요.

![](<../../.gitbook/assets/5 (8).png>)

### 구독 확인 이메일 수정하기

\[구독 확인 이메일 → 수정하기]에서 아래 항목을 수정할 수 있습니다.

* 발신자 이름, 발신자 이메일 주소: 기본값은 주소록의 발신자 이름과 발신자 이메일 주소입니다.
* 콘텐츠: 구독 확인 이메일의 본문입니다.
* 버튼: 구독 확인 버튼의 이름, 배경 색상, 텍스트 색상을 바꿀 수 있습니다.

\[미리보기]를 클릭하면 구독 확인 이메일이 어떻게 보이는지 확인할 수 있습니다.

**\*주의:** 구독 확인 이메일에서는 메일머지가 동작하지 않습니다. 주소록 정보를 수정해도 구독 확인 이메일의 내용은 자동으로 바뀌지 않으므로 따로 수정해 주세요.

## 내 홈페이지에 구독 폼 넣기 <a href="#adding-subscription-form" id="adding-subscription-form"></a>

구독 폼을 HTML 코드로 복사해 홈페이지나 블로그에 직접 넣을 수 있습니다. 원하는 위치에 구독 폼을 둘 수 있고, 코드를 수정할 수 있다면 구성과 디자인도 자유롭게 바꿀 수 있습니다.

1. \[주소록 → 구독 화면 → 구독 폼]으로 이동합니다.
2. \[코드로 설치하기]를 클릭합니다.
3. \[모두 복사하기]를 클릭해 HTML 코드를 복사합니다.
4. 홈페이지 또는 블로그에 코드를 붙여 넣습니다.

언어를 '영어'로 선택하면 영어 버전의 HTML 코드도 사용할 수 있습니다. 단, 구독 폼의 제목, 내용, 입력 항목, 버튼 문구는 \[수정하기]에서 직접 바꿔야 합니다.

코드로 설치한 구독 폼이 궁금하다면 아래 예시를 참고해 주세요.

* [스티비 블로그](https://blog.stibee.com/nurturing-email-for-sales-conversion)

{% hint style="info" %}
홈페이지나 블로그의 특성에 따라 붙여 넣은 구독 폼이 스티비에서 편집한 것과 다르게 보일 수 있습니다. 이 경우 사용하는 서비스의 담당자나 제공 업체에 문의해 주세요.
{% endhint %}

### 코드로 설치할 때 참고사항

* HTML 코드만 제공합g낱니다. CSS는 직접 수정해야 합니다.
* `id`, `class` 값을 수정하면 정상적으로 동작하지 않을 수 있습니다.
* 한 페이지에는 구독 폼을 하나만 넣을 수 있습니다.
* 스티비 기능이 업데이트되거나 구독 폼 내용을 수정했다면, 코드를 다시 복사해 교체해야 합니다. 코드로 설치한 구독 폼에는 변경 사항이 자동으로 반영되지 않습니다.
* 자동 입력 방지(reCAPTCHA)는 적용되지 않습니다.

![](<../../.gitbook/assets/8 (8).png>)



구독 폼뿐만 아니라 \[페이지]를 사용해도 구독 신청을 받을 수 있습니다. 페이지를 사용한 구독 방법은 [페이지로 구독자 모으기](../../page/subscribe/) 도움말을 참고해 주세요.
