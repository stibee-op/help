# 구독 정보 직접 수정하기

## 이 글에서는

구독자는 '구독 정보 변경 화면'에서 자신의 구독 정보를 직접 수정할 수 있습니다. 구독 정보 변경 화면의 URL을 확인하는 방법과 구독자가 정보를 변경하는 과정을 안내합니다.

***

## 구독 정보 변경 화면 URL 확인하기

구독 정보 변경 화면의 URL은 \[주소록 → 구독 관리 화면 → 구독 정보 변경 화면]에서 확인할 수 있습니다.

URL은 아래 형식으로 만들어집니다.

* 형식: https://page.stibee.com/subscribers/auth/{listid}
* 예시: https://page.stibee.com/subscribers/auth/3

_\* {listid}는 주소록 ID입니다. \[주소록 대시보드]의 URL에서 lists 뒤에 표시되는 숫자를 넣으면 됩니다._

## 구독 정보 변경하기

구독자는 아래 순서로 구독 정보를 변경합니다.

1. 구독 정보 변경 화면 URL에 접속합니다.
2. 구독자로 등록된 이메일 주소를 입력한 뒤, \[구독 정보 변경 링크 보내기]를 클릭합니다.
3. 입력한 이메일 주소로 받은 확인 이메일에서 \[네, 이메일 주소가 맞습니다]를 클릭합니다.
4. 구독 정보 오른쪽 \[변경하기]를 클릭해 정보를 변경합니다. 이메일을 더 받고 싶지 않다면 \[수신거부]를 클릭합니다.

**\*주의:** 확인 이메일의 링크는 24시간 동안만 사용할 수 있습니다. 24시간이 지났다면 \[구독 정보 변경 링크 보내기]를 다시 클릭해 새 이메일을 받아 주세요.

### **확인할 수 있는 정보**

구독 정보 변경 화면에는 아래 날짜가 표시됩니다.

* 구독일: 모든 구독자에게 표시됩니다.
* 광고성 정보 수신동의일: 광고성 정보 수신에 동의한 적이 있을 때 표시됩니다.
* 광고성 정보 수신거부일: 동의를 철회한 적이 있을 때 표시됩니다.
